# Rockets-Fan-App

A lightweight end-to-end Rockets fan app experience focused on younger-fan engagement.

## Features

- Daily check-in with fan points and streak tracking
- Rockets trivia quiz with instant feedback and score rewards
- Next tipoff countdown for game-day excitement
- Player spotlight cards with youth-friendly highlight themes

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run test
npm run build
```
